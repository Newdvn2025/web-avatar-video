# 用户逐步教程

目标：用自己的角色图做一个能随鼠标方向转头、随滚动做动作的网页。先做第一屏，满意后再补其他章节。

每步对应提示词见 [全流程工具箱](prompts.md)：A1角色 → A2衣服 → A3脸与眼睛 → A4透明图（可选） → B视频 → C1验片 → C2抠图 → C3校准 → D1网页 → D2背景 → D3动效 → D4封面 → E验收。

先在工具箱变量表填好自己的风格、服装、画幅、时长与项目路径。`{{变量名}}` 需替换，不确定时请助手按默认值填好整段。

## 第一步：确定人物
上传清楚的正面照片，生成一个全身3D卡通外观角色。先选衣服，再调整脸型与眼睛，最后定稿。眼镜、发型、衣服、鞋子以后都用同一张图，不要每段重新设计。此步骤生成的是角色图片，不是3D模型。

## 第二步：生成一条环绕转头视频
打开你能使用的图生视频平台，上传定稿图。使用 [prompts.md](prompts.md) 的完整环绕提示词。示例为12秒、3:4、纯白背景；平台不支持时长时压缩时间表，并记录实际结果。选最高可用分辨率，下载原文件，不经聊天软件二次压缩。

先检查：是否每个方向都看到了、瞳孔是否跟着转、有没有多余的小点、脸型有没有变化、身体是否突然晃动。不要没看结果就继续花额度补片。

## 第三步：让AI处理素材
把视频发给助手并说：“使用 web-avatar-video Skill，检查方向、抠透明背景，制作第一屏Demo。”在本包支持的macOS环境，助手可运行 prepare_frames.py。其他系统需准备等价分割工具。

网页素材按原视频尺寸处理；不能承诺超分辨率能恢复原本没有的细节。检查角色在深色和浅色背景上都没有明显边缘残留。

## 第四步：校准与启动
助手按实际视频校准每个方向的时间，并改Demo的帧数、尺寸和方向键。不要原样套用本案例的帧时间到新视频。

在技能文件夹启动：
```sh
python3 -m http.server 8091
```
打开 http://localhost:8091/assets/demo/ 。移动鼠标绕页面中心一圈，检查上下左右和四个斜方向。中心区域回正，鼠标离开窗口回正。

## 第五步：补滚动动作（可选）
使用提示词中的指向、展示、挥手三个动作。每段6秒，同一角色、同一构图。抠透明后分别放入action-1、action-2、action-3，修改帧数设置。上下滚动检查正放和倒放。

## 第六步：接入网站
先保留独立Demo，再接入现有介绍页。保持路径、Canvas宽高、文件数量一致。手机没有悬停鼠标，第一屏静态；后续章节仍可滑动控制动作。系统选择减少动态效果时静态展示。

交付物：原图、原视频清单、完整提示词、透明帧、方向时间表、网页代码、效果截图、局限说明。

## 这个方法能做什么
能做有3D外观的网页展示、方向跟随和滚动手势。不能替代带骨骼的3D角色；鼠标半径不能连续改变俯仰幅度；视频生成的轻微比例变化仍可能存在。需要精确看向任意空间点时用真正3D模型和绑定方案。
