# 网页交互人物 · 全流程提示词工具箱

从照片到角色、从视频到网页，每一步都有可直接复制的模板。

## 怎么使用

1. 用下方变量表填好自己的需求。`{{变量名}}` 是需要替换的内容，花括号一起删除。
2. 上传该步骤要求的照片、定稿图或视频，再复制整个提示词给对应AI。
3. 不确定怎么填时，直接让助手：“按默认值填好变量，输出这一阶段完整最终提示词，不要让我手动拼接。”
4. 不必一次跑所有步骤。角色已定稿就跳过角色阶段；先完成环绕视频，再决定是否补滚动动作。

**工具区分：** A阶段和背景生成给图像AI；B阶段给图生视频AI；C、D阶段给能读取本地文件并修改代码的编程助手。视频模型不能执行抽帧或写网站。

## 可调变量

|变量|填写示例 / 默认值|作用与调整范围|
|---|---|---|
|`{{人物身份}}`|我的个人网站作者形象|人物用途，不必填真实姓名|
|`{{角色风格}}`|温暖的3D卡通，轻微毛毡质感，成人比例|可换黏土、玩具、动漫等；定稿后所有视频保持一致|
|`{{保留特征}}`|短黑发、细框眼镜、自然脸型|从照片中选择辨识特征，不编造照片里没有的特征|
|`{{服装方向}}`|银灰科技外套、青色细节、黑色工装裤|九宫格时可探索；选定后锁定|
|`{{定稿服装}}`|参考图中已选定的完整服装|全部视频必须沿用同一套|
|`{{卡通程度}}`|轻度卡通，保留本人辨识度|可描述更圆润、更夸张，避免与写实要求冲突|
|`{{眼睛质感}}`|自然棕色虹膜、柔和高光、双眼同向|外观可调，眼球协调运动要求保留|
|`{{角色画幅}}`|3:4|可换4:5等；同组视频统一，完整全身|
|`{{环绕时长}}`|12秒|取平台支持值；助手应按比例重写完整时间表|
|`{{手势时长}}`|6秒|取平台支持值；同步重写时间表|
|`{{转头幅度}}`|左右20度、上下15度|小幅为主，大幅可能露出不稳定侧脸|
|`{{身体伴随}}`|轻微呼吸，上半身左右跟随3—5度|可改为身体固定；禁止和“不动”同时出现|
|`{{素材路径}}`|本机视频的绝对路径|编程助手处理输入|
|`{{输出目录}}`|项目内新建的avatar-assets目录|不覆盖原文件；路径由用户环境决定|
|`{{网站目录}}`|你的网站项目绝对路径|接入现有项目用|
|`{{抽帧率}}`|12|1—30；更高更顺但体积和内存更多|
|`{{背景风格}}`|CG厚涂、深色梦幻、奇幻赛博|可换自然、极简、漫画等，不改角色身份|
|`{{主色}}` / `{{辅助色}}`|青色 / 紫色|背景、灯光、UI统一|
|`{{视觉元素}}`|传送门、远山、薄雾、水晶|只用于背景；不写进纯背景动作视频|
|`{{网站用途}}`|个人介绍与作品集|决定文字和布局|
|`{{页面标题}}`|从一张图，唤醒另一个你|网页与封面标题|
|`{{项目名称}}`|Web Avatar Video|封面英文项目名|
|`{{作者署名}}`|自己的名字或品牌名|封面署名|
|`{{封面画幅}}`|1200×630|GitHub/网页横版；小红书另选3:4并重新排版|

**不建议改掉的约束：** 同一张定稿图、固定镜头、完整角色、统一画幅、原文件下载、眼球自然协调、动作视频不新增物体。不要把抽帧率当作源视频分辨率；它们是两个不同参数。

## 第一屏：环绕转头，12秒
```text
生成一段12秒的3D卡通角色动画，以参考图中的人物为唯一角色，严格保持脸型、眼镜、发型、服装、身体比例和材质一致，保留参考图的卡通质感。
固定正面镜头，竖版3:4，纯白背景，柔和均匀照明。人物居中，全身完整，头顶和脚底留出空间，人物大小保持稳定。
人物站在原地，双脚固定，不迈步、不明显改变重心。身体有非常轻微的自然呼吸，肩膀小幅起伏。头部左右转动时，上半身可以同方向轻轻跟随约3—5度。双臂自然垂放，双手和手指放松，只做细微伴随运动，不抬手、不做独立手势。
头部和眼球是主要动作。左右均指观看者看到的画面方向：
0—1秒：正面，双眼看向镜头。
1—2秒：缓慢看向画面左侧。
2—3秒：缓慢看向画面左上方。
3—4秒：缓慢看向画面正上方。
4—5秒：缓慢看向画面右上方。
5—6秒：缓慢看向画面右侧。
6—7秒：缓慢看向画面右下方。
7—8秒：缓慢看向画面正下方。
8—9秒：缓慢看向画面左下方。
9—10秒：缓慢看向画面左侧。
10—11秒：缓慢回到正面，上半身恢复初始姿态。
11—12秒：保持正面，双眼看向镜头。
左右转头约20度，抬头和低头约15度。相邻方向连续平滑过渡，不突然跳转，不做大幅绕颈动作。
每次改变方向，双眼先自然转动，头部稍后跟随。两只眼睛协调转动，虹膜和瞳孔随方向同步移动，不能只有头动、眼睛始终看镜头。眼睑自然调整，虹膜和瞳孔自然可见，瞳孔大小稳定。不斗鸡眼、不翻白眼、不露出过多眼白，不让眼球抖动或变形。
眼镜稳定，镜片反光不遮挡眼睛。保持轻微微笑，不说话。身体运动克制，与转头协调，首尾姿态和表情尽量一致。
画面只包含人物和纯白背景，不出现小点、光点、圆球、指针、标记、文字、道具或其他物体。无镜头移动、无缩放、无剪辑、无大幅身体摇摆、无突然耸肩、无服装变化、无人脸变化。
```
